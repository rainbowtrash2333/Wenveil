## 4. 已知限制

- 当前默认离线规则链已经可用，但 Qwen 小模型仍是可选适配器，仓库不包含模型权重。
- 白名单是精确词典制度；新增机构名称需要人工评审后修改规则文件，不使用模糊通配。
- 当前输入边界是 OCR 后的 Markdown/纯文本；图片 OCR 由上游流程提供。
- 项目没有 GUI；CLI 冒烟和集成验收替代页面端到端测试。
- 审计只能覆盖已定义的高风险形态和 Token/Markdown 结构，正式上线仍需用授权真实语料做独立残留评估。
