# Wenveil 桌面端 UI 设计

## 1. 产品定位

Wenveil 面向普通用户，提供本地文档文字识别、文本整理、敏感信息脱敏和脱敏恢复能力。

设计目标：

* 操作简单。
* 默认离线运行。
* 支持单文件、多文件和文件夹处理。
* 支持完整流水线一次执行。
* 支持用户自由选择需要执行的处理步骤。
* 尽量自动判断文件类型和处理方式。
* 整体界面现代、简洁、清晰。

# 5. 处理流程

完整流程：

```text
原始文档
   ↓
文字识别
   ↓
文本整理
   ↓
文档脱敏
   ↓
脱敏检查
   ↓
处理完成
```

默认全部选中：

```text
☑ 文字识别
☑ 文本整理
☑ 文档脱敏
☑ 脱敏检查
```

用户也可以自由取消某一步。

例如只做 OCR：

```text
☑ 文字识别
☐ 文本整理
☐ 文档脱敏
☐ 脱敏检查
```

OCR + 整理：

```text
☑ 文字识别
☑ 文本整理
☐ 文档脱敏
☐ 脱敏检查
```

已有文本直接脱敏：

```text

☑ 文本整理
☑ 文档脱敏
☑ 脱敏检查
```

# 17. 脱敏检查

开启后，在脱敏完成后自动检查结果。

正常：

```text
✓ 未发现明显的敏感信息残留
```

需要注意：

```text
! 发现 2 处可能需要人工确认
```

当前界面只把该结果标记为“建议检查”，不展示逐条审计明细。审计类别限于
`desensitize/audit.py` 覆盖的高风险形态：手机号、座机、邮箱、证件号、银行账号、
合同编号、地址，以及 Token 完整性和 Markdown 表格结构；人名和机构名称不在审计类别中。

# 19. 输出文件

根据用户选择的步骤生成对应结果。

例如设置密码的可恢复流程：

```text
document-xxxx.masked.md
document-xxxx.mapping.enc
document-xxxx.report.json
```

如果用户需要保留中间结果，可以在设置中开启。

未设置密码时只生成：

```text
document-xxxx.masked.md
document-xxxx.report.json
```

此时没有 mapping，不能进入恢复流程。

```text

   ↓
```

```text
   ↓
脱敏
   ↓
检查
   ↓

```

这样桌面端保持简单，同时现有 Python 核心可以继续独立维护。
